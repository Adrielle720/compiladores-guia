Até o Roteiro 5, todo programa rodava cada linha exatamente uma vez, de cima para baixo. O Roteiro 6 traz duas coisas novas: a execução passa a escolher um caminho (if/else) e a voltar para trás (for, que em Go faz o papel do while). Para isso aparecem os operadores booleanos e relacionais, as chaves de bloco e a leitura do terminal. A meta do roteiro é o fatorial:

i = 1
n = 5
f = 1
if n < 2 {
    f = 1
} else {
    for i < n || i == n {
        f = f * i
        i = i + 1
    }
}

Esta aba é em Java. O código ativo do depurador é uma referência do Roteiro 6, escrita no mesmo estilo de um main.java do Roteiro 5 (classes Lexer, Parser, Node, enum TipoToken). O enunciado pede que você escreva a sua própria EBNF: use isto para estudar, não para copiar.

A gramática (uma proposta)

O diagrama da aula é o de C, com parênteses no if. Adaptado para o Go, fica assim. As linhas marcadas com ★ são novas em relação ao Roteiro 5:

PROGRAM         = { STATEMENT } ;
BLOCK           = "{", { STATEMENT }, "}" ;                              ★
STATEMENT       = ( λ | ASSIGNMENT | PRINT | IF | FOR ), "\n" ;
ASSIGNMENT      = IDENTIFIER, "=", BOOL_EXPRESSION ;
PRINT           = "Println", "(", BOOL_EXPRESSION, ")" ;
IF              = "if", BOOL_EXPRESSION, BLOCK, [ "else", BLOCK ] ;          ★
FOR             = "for", BOOL_EXPRESSION, BLOCK ;                           ★
BOOL_EXPRESSION = BOOL_TERM, { "||", BOOL_TERM } ;                        ★
BOOL_TERM       = REL_EXPRESSION, { "&&", REL_EXPRESSION } ;              ★
REL_EXPRESSION  = EXPRESSION, { ("==" | ">" | "<"), EXPRESSION } ;         ★
EXPRESSION      = TERM, { ("+" | "-"), TERM } ;
TERM            = FACTOR, { ("*" | "/"), FACTOR } ;
FACTOR          = NUMBER | IDENTIFIER | ("+" | "-" | "!"), FACTOR
                | "(", BOOL_EXPRESSION, ")" | "Scanln", "(", ")" ;      ★

A precedência sai da escada de funções, igual ao Roteiro 3: quanto mais fundo o degrau, mais forte o operador. Da mais forte para a mais fraca: ! + - (unários) → * / → + - → == > < → && → ||. Por isso 1 + 2 * 3 == 7 && !0 || 0 se lê como (((1 + (2*3)) == 7) && (!0)) || 0. Carregue esse exemplo no depurador e veja a árvore.

Pegadinhas

O "\n" depois do "{"

É só uma linha vazia dentro do bloco: vira um NoOp. Nenhuma regra especial é necessária, e você vê esse NoOp na AST.

O "\n" depois do "}"

Fecha o statement do if/for. Por isso o } else { precisa ficar numa linha só, que é também a regra do Go.

Booleano é int

Relacionais devolvem 1 ou 0, e If/While testam != 0. Por isso Println(3 > 2) imprime 1.

Scanln é FACTOR

Ele devolve valor, então pode aparecer no meio da conta: x = Scanln() + 1. Já o Println é statement.

While reavalia a condição

Um laço de 3 voltas avalia a condição 4 vezes. No depurador, veja volta subir na pilha.

Laço infinito

Esquecer o i = i + 1 trava o Java para sempre. O depurador para em 20 000 passos e avisa.

Extra credit

if como expressão (n = if x > 2 { 5 } else { 3 }): um novo caminho no FACTOR, com a maior precedência de todas, que devolve um nó de 3 filhos (condição, valor-então, valor-senão). O evaluate dele devolve um dos dois valores, em vez de 0. for estilo C (for i = 0; i < n; i = i + 1 { … }) pode ser só açúcar sintático: o Parser monta Block[ Assignment(init), While(cond, Block[ corpo…, Assignment(passo) ]) ], sem nenhuma classe nova.
