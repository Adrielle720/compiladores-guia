O Roteiro 5 é o maior salto do curso: o compilador deixa de avaliar uma expressão e passa a executar um programa, uma instrução por linha, com variáveis que guardam valores entre uma linha e outra. A meta do roteiro:

// Comentário!
x1 = 3
y2 = 4
z_final = x1 + y2
Println(z_final)

Esta aba é em Java, com o seu código de verdade: o painel "Código" mostra o main.java da tag v2.0.2, sem nenhuma alteração. O depurador reimplementa cada método e foi conferido contra o javac: mesmas saídas e mesmas mensagens de erro.

A gramática

PROGRAM    = { STATEMENT } ;
STATEMENT  = ( λ | IDENTIFIER, "=", EXPRESSION | "Println", "(", EXPRESSION, ")" ), "\n" ;
EXPRESSION = TERM, { ("+" | "-"), TERM } ;
TERM       = FACTOR, { ("*" | "/"), FACTOR } ;
FACTOR     = NUMBER | IDENTIFIER | ("+" | "-"), FACTOR | "(", EXPRESSION, ")" ;
IDENTIFIER = LETTER, { LETTER | DIGIT | "_" } ;
NUMBER     = DIGIT, { DIGIT } ;
